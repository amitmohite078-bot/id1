# `@salonbridge/db`

Drizzle ORM schema, PostGIS custom types, SQL migrations, and seed scripts for SalonBridge.

## Commands
- `pnpm db:generate` — Generate Drizzle SQL migrations from schema changes
- `pnpm db:migrate` — Apply pending migrations
- `pnpm db:seed` — Seed roles, plans, global categories, platform configs, and dev super-admin
